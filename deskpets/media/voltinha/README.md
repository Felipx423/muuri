# Voltinha

Assets do Voltinha para o Muuri, produzidos em canvas transparente de 128 x 128 px.

A imagem em `references/voltinha-canonical.png` é a referência visual fornecida pelo usuário. A base em `source/master.png` foi preparada com a ferramenta integrada de geração de imagens, preservando a seta verde, o contorno, o rosto, os membros flutuantes e os padrões internos. Todas as animações são transformações dessa mesma base e podem ser reproduzidas com `source/animate.py`.

Estados: `idle`, `walk`, `walk_fast`, `run`, `swipe`, `lie` e `drag`.
