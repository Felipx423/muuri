# Changelog

## Muuri [1.3.0]
### Added
- Eco, com sete animações transparentes de 128 px e locomoção lateral.
- Limite global de seis pets, com contador e bloqueio de novas adições no painel.
### Changed
- Configurações antigas acima do limite exibem somente os primeiros seis pets, sem reescrever preferências automaticamente.
- Instalação e atualização pelo aplicativo preservam as preferências existentes.

## [1.2.0]
### Added
- Settings panel
- Display pets in front or back of other windows
- Automatically hide pets when fullscreen

## [1.1.0]
### Fixed
- Crash after 15-20 min (https://github.com/Jumitti/DeskPets/issues/1)

## [1.0.0]
### Added
- First commit
- Unlimited number of pets
- Some species support multiple color variations
- Per-species size control
- Position automatically adapts to the taskbar
- Simple interaction: some pets sit when the cursor gets close
